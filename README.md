# Partner Portal Next.js Starter

A GitHub/Vercel-ready headless starter portal for affiliates and brokers.

## Included routes
- `/`
- `/dashboard`
- `/onboarding`
- `/training`
- `/affiliate-links`
- `/resources`
- `/performance`
- `/support`

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS

## Run locally
```bash
npm install
npm run dev
```

## Push to GitHub
```bash
git init
git add .
git commit -m "Initial partner portal"
git branch -M main
git remote add origin YOUR_GITHUB_REPO_URL
git push -u origin main
```

## Deploy to Vercel
Import the GitHub repo into Vercel and deploy.

## Notes
This starter uses mock data from `lib/data.ts`.
Replace that file with your own CMS/API/CRM integration later.
