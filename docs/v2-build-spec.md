# Moonshine Capital Partner OS — V2 Build Spec

## Objective
Build a headless, activation-first partner portal that:
- Activates new affiliates quickly
- Drives consistent deal flow
- Supports training, tools, and performance tracking
- Scales into a Capital Ops ecosystem

## Core Philosophy
This is NOT a generic dashboard.

This is:
- Activation OS
- Revenue engine
- Training + deal flow system

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase (Auth + DB)
- Vercel (hosting)
- Optional:
  - HubSpot (CRM)
  - Google Sheets (admin imports)
  - Notion (content source)

## Core Modules
- Auth (Supabase)
- Dashboard (activation + performance)
- Offers (partner programs)
- Training (structured learning)
- Playbooks (vertical strategies)
- Resources (assets + scripts)
- Tools (widgets, calculators)
- Performance (metrics + tracking)
- Support (booking + help)
- Admin (content + partner management)

## UX Direction
- Editorial Bento layout
- Neo-brutalist accents
- Dark theme, high contrast
- Operator-first UI (fast, punchy, actionable)

## Success Criteria
- Partner completes onboarding in < 15 minutes
- First link shared within session
- First deal activity within 48–72 hours
